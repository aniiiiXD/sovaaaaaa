# Money

A Next.js starter website for an applied AI company.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Contact button

Create `.env.local` and set `NEXT_PUBLIC_CONTACT_EMAIL` to your real contact address. Restart the server after changing the file. Without an address, the contact section says that contact details are coming soon.

The industry examples are illustrative, not customer case studies. The hero image is generated; industry photographs are from Unsplash.
